# Privacy Policy

Last updated: September 13, 2026

Home School Media Import is a personal, single-user application operated by its account owner.

## Google user data accessed

The application uses read-only Google Drive access to retrieve file metadata and file content. Although the OAuth scope may permit broader read access, the application is operationally configured to access only a designated folder authorized by the account owner.

## Use of data

The accessed data is used only to copy authorized media files to the account owner's private household storage and backup system. It is not used for advertising, profiling, analytics, or training artificial intelligence systems.

## Storage and sharing

Downloaded files are stored on private household storage and may be included in an encrypted off-site backup. Google user data is not sold or publicly shared. OAuth credentials are stored in an access-controlled encrypted configuration.

## Retention and deletion

Downloaded files are retained until the account owner deletes them. Deleting a source file from Google Drive does not automatically delete an archived copy.

## Revoking access

The account owner may revoke the application's access at any time through Google Account security settings.

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
