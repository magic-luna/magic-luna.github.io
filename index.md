# Magic Luna Personal Applications

This site describes personal, single-user applications operated by their account owner. These applications are not offered to the public and do not sell, advertise with, or publicly share Google user data.

## Home School Media Import

Home School Media Import copies media files from an authorized Google Drive folder to private household storage.

[Privacy Policy](privacy)

## LunaGmail

LunaGmail is a personal Gmail assistant that processes messages intentionally placed under a designated label, produces summaries and reminders for the account owner, manages workflow labels, and sends operational notifications only to the same authorized Gmail account.

[Application Homepage](lunagmail/) · [Privacy Policy](lunagmail/privacy) · [Terms of Service](lunagmail/terms)
