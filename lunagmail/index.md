# LunaGmail

LunaGmail is a personal, single-user Gmail assistant operated by the Gmail account owner on the owner's private computer.

The application uses Gmail access to:

- find and read messages that the account owner intentionally places under a designated workflow label;
- summarize those selected messages for the account owner;
- move processed messages between designated workflow labels; and
- send task reminders, processing summaries, and operational alerts only to the same authorized Gmail account.

LunaGmail is not offered to the public. It does not sell Google user data, use it for advertising or profiling, or publicly share it.
